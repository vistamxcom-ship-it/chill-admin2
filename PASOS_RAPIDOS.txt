════════════════════════════════════════════════════════════════════
                    PASO 1: LOCAL (2 minutos)
════════════════════════════════════════════════════════════════════

1. Instalar dependencias
   npm install

2. Probar localmente
   npm start
   → Ir a http://localhost:3000

✅ Función correctamente en local? SIGUIENTE PASO

════════════════════════════════════════════════════════════════════
                  PASO 2: VERCEL (Frontend) (3 minutos)
════════════════════════════════════════════════════════════════════

1. Ir a https://vercel.com (crear cuenta si no tienes)

2. Click "New Project" → Importar este repositorio de GitHub

3. Configurar:
   - Framework: Other (no build needed)
   - Root: .
   - Build: echo 'Static'
   - Output: .

4. Click "Deploy"

5. Esperar ~2 minutos

📝 COPIAR LA URL:
   ├─ Tu frontend estará en: 
   └─ https://cashazo-admin-XXXXXX.vercel.app

✅ Frontend LISTO y accesible desde cualquier dispositivo

════════════════════════════════════════════════════════════════════
               PASO 3: FLY.IO (Backend) (7 minutos)
════════════════════════════════════════════════════════════════════

1. Instalar Fly CLI:
   macOS: brew install flyctl
   Linux: curl -L https://fly.io/install.sh | sh

2. Login:
   flyctl auth login
   (Abre navegador, crea cuenta gratis, confirma)

3. Crear app:
   flyctl launch
   
   Responde:
   - App name: cashazo-admin
   - Region: sjc (o la más cercana)
   - Postgres: NO
   - Redis: NO

4. Configurar secretos (variables de entorno):
   flyctl secrets set SUPABASE_URL="https://heljnwezenhdaxjcevti.supabase.co"
   flyctl secrets set SUPABASE_KEY="sb_publishable_JEl1Zq6hs0sbGQ32Y1uzaA_7Px1gXkq"
   flyctl secrets set NODE_ENV="production"

5. Desplegar:
   flyctl deploy
   (Espera 3-5 minutos)

📝 COPIAR LA URL:
   ├─ Tu backend estará en:
   └─ https://cashazo-admin.fly.dev

✅ Verificar que funciona:
   https://cashazo-admin.fly.dev/api/health
   (Debe mostrar: {"status":"ok","supabase":"connected"})

════════════════════════════════════════════════════════════════════
              PASO 4: CONECTAR (Frontend ↔ Backend)
════════════════════════════════════════════════════════════════════

OPCIÓN A: Modificar admin-optimizado.html
   Buscar: const serverUrl = 'http://localhost:3000'
   Cambiar a: const serverUrl = 'https://cashazo-admin.fly.dev'

OPCIÓN B: Variable de entorno en Vercel
   En Vercel dashboard → Settings → Environment Variables
   Agregar: NEXT_PUBLIC_API_URL = https://cashazo-admin.fly.dev

Si modificaste Opción A:
   git commit -am "Update API URL"
   git push
   (Vercel redeploya automáticamente)
